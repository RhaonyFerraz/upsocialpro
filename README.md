O **UpSocial Pro** é uma plataforma web moderna, rápida e altamente otimizada para a venda de serviços de crescimento orgânico e autoridade digital nas redes sociais (**Instagram, TikTok, Kwai, YouTube, Telegram e Twitter/X**).

---

## 🌟 Principais Funcionalidades

### 1. ♀♂ Segmentação por Gênero (Feminino / Masculino / Todos)
- Permite que o cliente filtre e contrate seguidores direcionados para o seu público-alvo específico (ideal para nichos de moda, estética, fitness, etc.).

### 2. 🤖 Assinaturas Mensais Automatizadas por Inteligência Artificial
- O cliente cadastra o perfil 1 única vez e o sistema monitora novas postagens, entregando curtidas, visualizações e comentários automaticamente a cada novo Reels ou foto.

### 3. 🧮 Calculadora Avançada de Pacotes Personalizados
- O usuário escolhe a quantidade exata de interações desejadas por meio de um slider interativo e recebe um desconto progressivo automático.

### 4. 🕒 Widget de Horários de Atendimento & Suporte VIP
- Janela interativa exibindo os horários oficiais do suporte humano com direcionamento instantâneo via WhatsApp.

### 5. ⚙️ Suporte Total a Variáveis de Ambiente (`.env`)
- Centralização de números de WhatsApp, e-mail de suporte, dias de garantia, percentuais de desconto e métricas em arquivo de configuração `.env`.

### 6. 📱 Design 100% Responsivo e Adaptativo
- Interface ultraconfortável em telas mobile, tablets, notebooks e monitores ultrawide.

## 🚀 Como Executar Localmente

1. **Clonar o Repositório**:
   ```bash
   git clone https://github.com/SEU_USUARIO/upsocialpro.git
   cd upsocialpro
   ```

2. **Configurar as Variáveis de Ambiente**:
   Copie o arquivo `.env.example` para `.env` e configure com as suas informações:
   ```bash
   cp .env.example .env
   ```

3. **Iniciar um Servidor Local**:
   Você pode usar qualquer servidor HTTP simples. Por exemplo, com `npx serve`:
   ```bash
   npx serve . -p 8080
   ```
   Ou abrindo diretamente o arquivo `index.html` em seu navegador.
